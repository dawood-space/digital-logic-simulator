DIGITAL LOGIC GATE & CIRCUIT SIMULATOR (NO JAVASCRIPT)

1. Install Python 3 from python.org (if not installed).
2. Open a terminal in this folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000 in your browser.
6. Choose a gate, change inputs P and Q, and click Run simulation.
7. Press Ctrl+C in the terminal to stop the server.

All logic calculations are performed in Python. HTML and CSS render the dashboard.
Internet is only needed for installing Flask, not for using the app afterward.
